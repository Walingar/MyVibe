# 2026-03-15

## Decision: Single application-level ProjectFrame

- What: switched to one persistent `ProjectFrame` that is not tied to a host project.
- Why: remove visual project-switch churn and keep one stable frame for the whole app lifecycle.
- How: no-project mode now uses `IdeProjectFrameHelper` + `ToolWindowPane`; project open flow reuses existing helper instead of creating a second frame helper.

## Decision: Remove welcome screen runtime flow

- What: removed welcome-screen runtime branches and registrations from platform configuration.
- Why: product flow now requires no welcome UI at startup or on project close.
- How: simplified close-window logic to no-project frame/exit behavior, removed welcome EP registrations from platform XML, and removed welcome-tab opening path from project/editor restore flow.

## Decision: Documentation policy changed to daily logs

- What: replaced feature-based docs requirement with daily logs in `docs/daily`.
- Why: keep decision history centralized by date and easier to maintain during large refactors.
- How: updated `AGENTS.md` to require `docs/daily/YYYY-MM-DD.md` updates for every workday.
